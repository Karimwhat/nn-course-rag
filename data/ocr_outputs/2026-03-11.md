# Batch Normalization
*March 11, 2026 | 8:33 AM*

**Idea:** Data on the same range for each batch will improve training.

Typically:
$$y = \sigma(Wx + b)$$

Apply batch normalization prior to activation:
$$\Gamma = Wx + b$$
$$\Gamma^{BN} = \frac{\Gamma - \mu_\Gamma}{\sigma_\Gamma} \odot \alpha + \beta$$

*   $\Gamma$ - aggregations for a batch of data
*   $\vec{\Gamma}$ - each instance in batch is a vector
*   $\mu_\Gamma$ - mean of each feature
*   $\sigma_\Gamma$ - standard deviation for each feature
*   $\alpha$ - parameter that scales distribution
*   $\beta$ - parameter that shifts distribution

---

$$y = \sigma(\Gamma^{BN})$$

$\alpha, \beta$ are learnable parameters
*   do backprop to compute $\frac{\partial L}{\partial \alpha}, \frac{\partial L}{\partial \beta}$
*   update with gradient descent.

At inference time:
*   Compute $\mu_{train}, \sigma_{train}$
*   Use these values

This forces inputs to subsequent layers to have same range of values.

Easier to generalize across distributions with different shifts/scales.

Randomness of batching adds noise to shifting/scaling $\Rightarrow$ reduces overfitting.

# Autoencoders

COMP 4107 W2026 Page 2

---

Encoder: $h = f(x)$
Decoder: $\hat{x} = g(h)$

**Goal:** Reconstruct the output $\hat{x}$ to be as close as possible to input $x$.

Minimize $L(x, g(f(x)))$

Typically:
$$L = \frac{1}{2} \sum_i (x_i - \hat{x}_i)^2$$

**Undercomplete autoencoders:**
$$\text{size}(h) < \text{size}(x)$$

**Overcomplete autoencoders:**
$$\text{size}(h) > \text{size}(x)$$

$h$ is low-dimensional representation of $x$
