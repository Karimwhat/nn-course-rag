### Information Theory
Self-information $I(x)$ of an event $X = x$ is given by
$I(x) = -\log P(X=x)$

Have classifiers predict probability each class is true.

Suppose we have a classifier that predicts $P(\text{Class } i) = \hat{p}_i \quad \forall i$

Now suppose the true class for our input is $j$.
We have $\hat{p}_j$.

The event Class $j$ gives us $-\log(\hat{p}_j)$ information.
This tells how erroneous model is.

### Cross-Entropy Loss
CCE Loss $= - \sum_i y_i \log(\hat{p}_i)$

* $\hat{p}_i$ - predicted probability of class $i$
* $y_i$ - indicates if the true class is $i$

This computes self-information with event Class $i$.

BCE Loss $= -y \log \hat{p} - (1-y) \log(1 - \hat{p})$

* $y$ - true class label (0 or 1)
* $\hat{p}$ - probability predicted for class 1

### Gradient Descent
An iterative method to find the minimum of a function.

COMP 4107 W2026 Page 6

---

![Optimization Plot](https://i.imgur.com/example_opt_plot.png)

Consider a function of one variable $f(x)$

Taylor expansion of $f(\cdot)$ at $x$ to first order
$f(x + \epsilon) = f(x) + \epsilon f'(x)$

**Observe:**
1. If $f'(x) > 0$ and $\epsilon < 0$ then $f(x + \epsilon) < f(x)$
$\Rightarrow$ a small step in negative direction gives smaller value of $f$
2. If $f'(x) < 0$ and $\epsilon > 0$ then $f(x + \epsilon) < f(x)$
$\Rightarrow$ a small step in positive direction gives smaller value of $f$

### Gradient Descent (Single Variable)
Given a function $f(x)$, its minimum can...

---

...be estimated by:
1. Choose initial value $x$ and step size $\alpha$.
2. Compute $f'(x)$ at $x$.
3. Update $x \leftarrow x - \alpha f'(x)$.
4. Repeat.
