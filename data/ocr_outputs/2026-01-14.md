### Perceptron Model
Connections have real-valued weights

$f(x_1, \dots, x_n) = \sum_{i=1}^n w_i \cdot x_i$

![Perceptron Diagram](https://i.imgur.com/example_diagram5.png)
*Diagram: Inputs $x_i$ with weights $w_i$ entering the function $f(x_1, x_2, \dots, x_n)$ to produce output $y$.*

$y = \begin{cases} 1 & \text{if } f(x_1, \dots, x_n) \ge \text{threshold} \\ 0 & \text{otherwise} \end{cases}$ "binary"

*COMP 4107 W2026 Page 3*

---

$y = \begin{cases} 1 & \text{if } f(x_1, \dots, x_n) \ge \text{threshold} \\ -1 & \text{otherwise} \end{cases}$ "bipolar"

Add a constant input $x_0 = 1$ with associated weight $w_0$. 
"bias term"

$f(x_0, x_1, \dots, x_n) = \sum_{i=0}^n w_i \cdot x_i$

$y = \begin{cases} 1 & \text{if } f(x_0, \dots, x_n) \ge 0 \\ 0 & \text{otherwise} \end{cases}$

![Bias Perceptron Diagram](https://i.imgur.com/example_diagram6.png)

### Property:
* We can write any boolean function as a network of NAND neurons.
* In general, we can write any function as a network of neurons.

### Aggregation + Activation Functions

**Aggregation function:**
$f(x_0, \dots, x_n) = \sum_{i=0}^n w_i \cdot x_i$

**Activation function:**
1. $a(\cdot)$ is non-decreasing
2. $a(\cdot)$ is non-linear

*COMP 4107 W2026 Page 7*

---

### Heaviside Activation
$a(x) = \begin{cases} 1 & \text{if } x \ge 0 \\ 0 & \text{otherwise} \end{cases}$

### Logistic Function
$a(x) = \frac{1}{1 + e^{-x}}$

![Heaviside and Logistic Plot](https://i.imgur.com/example_plots1.png)

![Tanh and ReLU Plot](https://i.imgur.com/example_plots2.png)

### Tanh Activation
$a(x) = \tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$

*COMP 4107 W2026 Page 8*

### Rectified Linear Unit (ReLU) Activation

---

$a(x) = \begin{cases} 0 & \text{if } x < 0 \\ x & \text{if } x \ge 0 \end{cases}$
