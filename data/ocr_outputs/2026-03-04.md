**Preliminaries:**
$\frac{\partial L}{\partial o_t} = \frac{\partial L_t}{\partial o_t}$

$\frac{\partial L}{\partial h_t} = \frac{\partial L}{\partial o_t} \frac{\partial o_t}{\partial h_t} + \frac{\partial L}{\partial h_{t+1}} \frac{\partial h_{t+1}}{\partial h_t}$
$= \frac{\partial L_t}{\partial o_t} V + \frac{\partial L}{\partial h_{t+1}} \frac{\partial h_{t+1}}{\partial a_{t+1}} \frac{\partial a_{t+1}}{\partial h_t}$
$= \frac{\partial L_t}{\partial o_t} V + \frac{\partial L}{\partial h_{t+1}} \tanh'(a_{t+1}) W$

$\frac{\partial L}{\partial h_T} = \frac{\partial L_T}{\partial o_T} V$
$\frac{\partial L}{\partial h_{T-1}} = \frac{\partial L_{T-1}}{\partial o_{T-1}} V + \frac{\partial L}{\partial h_T} \tanh'(a_T) W$

Compute change in loss for parameters

$\frac{\partial L}{\partial c} = \sum_t \frac{\partial L}{\partial o_t} \frac{\partial o_t}{\partial c}$
$= \sum_t \frac{\partial L_t}{\partial o_t}$

$\frac{\partial L}{\partial V} = \sum_t \frac{\partial L}{\partial o_t} \frac{\partial o_t}{\partial V}$
$= \sum_t \frac{\partial L_t}{\partial o_t} h_t$

$\frac{\partial L}{\partial b} = \sum_t \frac{\partial L}{\partial h_t} \frac{\partial h_t}{\partial a_t} \frac{\partial a_t}{\partial b}$
$= \sum_t \frac{\partial L}{\partial h_t} \tanh'(a_t)$

$\frac{\partial L}{\partial W} = \sum_t \frac{\partial L}{\partial h_t} \frac{\partial h_t}{\partial a_t} \frac{\partial a_t}{\partial W}$
$= \sum_t \frac{\partial L}{\partial h_t} \tanh'(a_t) h_{t-1}$

$\frac{\partial L}{\partial U} = \sum_t \frac{\partial L}{\partial h_t} \frac{\partial h_t}{\partial a_t} \frac{\partial a_t}{\partial U}$
$= \sum_t \frac{\partial L}{\partial h_t} \tanh'(a_t) x_t$

### Computing $\partial L / \partial w_i$ on RNNs:

1. Forward propagate input $x_t$ to compute $a_t, h_t, o_t$ for all times $t$.
2. Backpropagate over time to compute $\partial L / \partial h_t$ for all $t$.
3. Compute partial derivatives of loss wrt. parameters using $\partial L / \partial h_t$ computed in Step 2.
