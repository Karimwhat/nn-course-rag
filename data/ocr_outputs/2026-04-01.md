# WHAT DOES “GENERATIVE” MEAN?
* **Discriminative**
  * Identify labels from features
  * [Image of digit 8] $\rightarrow$ 8

* **Generative**
  * Identify feature distribution from labels
  * 8 $\rightarrow$ [Image of digit 8]

# GAN TRAINING
1. Use generator to generate a set of fake images.
2. Classify images as real or fake.
3. Update discriminator with back-propagation.
4. Use generator to generate a set of fake images.
5. Update generator with back-propagation.
6. Repeat.

![Diagram showing combined training flow](https://pathmind.com/wiki/generative-adversarial-network-gan)

# VARIATIONAL AUTOENCODERS
* **Autoencoder**
  * Input $\rightarrow$ [Encoder] $\rightarrow$ Embedding $\rightarrow$ [Decoder] $\rightarrow$ Output
* **Variational Autoencoder**
  * Input $\rightarrow$ [Encoder] $\rightarrow$ [Distribution ($\mu, \sigma^2$)] $\rightarrow$ [Sample] $\rightarrow$ [Decoder] $\rightarrow$ Output
