### Multi-variable chain rule for differentiation
$z = f(x(t), y(t))$
$$\frac{\partial z}{\partial t} = \frac{\partial f}{\partial x} \frac{\partial x}{\partial t} + \frac{\partial f}{\partial y} \frac{\partial y}{\partial t}$$

**Example**
$f(x, y) = x^2 + y^2$
$x(t) = \ln(t)$
$y(t) = \sin(t)$

$\frac{\partial z}{\partial t} = 2x \cdot \frac{1}{t} + 2y \cdot \cos(t)$

$z = \ln(t)^2 + \sin(t)^2$
$\frac{\partial z}{\partial t} = 2 \ln(t) \cdot \frac{1}{t} + 2 \sin(t) \cdot \cos(t)$ [Labeled same]

### Backpropagation
Given a loss function $L$, we want to compute $\frac{\partial L}{\partial w_i}$ where $i$ indexes all weights in the network.

0. Forward propagate input through network. Store aggregations + activations in memory.

For each layer from output to input layer:
Define $s_k$ to be the aggregation in $k^{th}$ neuron of subsequent layer.
Define $w_{j,k}$ to be the weight of the connection associated with $j^{th}$ input and $k^{th}$ neuron of subsequent layer.
Define $r_j$ as the aggregation in $j^{th}$ neuron...

---

...of current layer.
Define $v_{i,j}$ as the weight of the connection associated with $i^{th}$ input and $j^{th}$ neuron of current layer.

**Case 1: Current layer is output layer.**
1. $\frac{\partial L}{\partial s_j} = \frac{\partial L}{\partial \hat{z}_j} a'(r_j)$. Store in memory for all nodes $j$.
2. $\frac{\partial L}{\partial v_{i,j}} = \frac{\partial L}{\partial s_j} x_i$.

**Case 2: Current layer is not output layer.**
1. Retrieve $\frac{\partial L}{\partial s_k}$ from memory for all nodes $k$.
2. $\frac{\partial L}{\partial r_j} = \sum_k \frac{\partial L}{\partial s_k} w_{j,k} a'(r_j)$. Store in memory for all nodes $j$.

### Differentiating Activation Functions
[Graphs provided for Heaviside, Logistic, Tanh, and ReLU functions]

**Heaviside function:**
$a(x) = \begin{cases} 1 & \text{if } x \ge 0 \\ 0 & \text{otherwise} \end{cases}$
$a'(x) = 0$

**Logistic:**
$a(x) = \frac{1}{1 + e^{-x}}$
$a'(x) = a(x)(1 - a(x))$

---

**Tanh:**
$a(x) = \tanh(x)$
$a'(x) = 1 - a(x)^2$

**ReLU:**
$a(x) = \begin{cases} x & \text{if } x > 0 \\ 0 & \text{otherwise} \end{cases}$
$a'(x) = \begin{cases} 1 & \text{if } x > 0 \\ 0 & \text{if } x \le 0 \end{cases}$

### Differentiating Loss Functions
**Regression tasks**
$L = \frac{1}{2} \sum_\ell (y_\ell - \hat{y}_\ell)^2$
$\frac{\partial L}{\partial \hat{y}_i} = \hat{y}_i - y_i$

**Classification tasks**
$L = -\sum_\ell y_\ell \log(\hat{p}_\ell)$
$\hat{p}_\ell$ is the predicted probability of class $\ell$

### Softmax Activation Function
Take $\hat{y}_i$ to be the output of the $i^{th}$ neuron in output layer prior to softmax.
Compute probabilities of each class as:
$$\hat{p}_i = \frac{e^{\hat{y}_i}}{\sum_\ell e^{\hat{y}_\ell}}$$
