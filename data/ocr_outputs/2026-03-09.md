## Pre-processing

### 1. Binning / Discretization
Given a set of thresholds $t_1, \dots, t_n$ we map continuous inputs to discrete inputs as:
$x^{BINNED} \leftarrow 0$ if $x < t_1$
$x^{BINNED} \leftarrow i$ if $t_i \le x < t_{i+1}$
$x^{BINNED} \leftarrow n$ if $t_n < x$

### 2. Normalization / Standardization
$x^{NORM} \leftarrow \frac{x - \min_x}{\max_x - \min_x}$
Force range for all features to be $[0, 1]$.

$x^{STAND} \leftarrow \frac{x - \mu_x}{\sigma_x}$
Force mean zero, standard deviation 1.

$\min_x, \max_x, \mu_x, \sigma_x$ are values associated with a feature. Computed on training set.

### Example
Medical diagnosis task.
Feature: temp of patient.
Threshold: $t_1 = 37^\circ C, t_2 = 38^\circ C$

$x = 40^\circ C \Rightarrow x^{BIN} = 2$
$x = 36^\circ C \Rightarrow x^{BIN} = 0$
$x = 37.5^\circ C \Rightarrow x^{BIN} = 1$

Over training set:
$\min_x = 34^\circ C, \max_x = 42^\circ C$
$\mu_x = 37^\circ C, \sigma_x = 1^\circ C$

$x = 38^\circ C \Rightarrow$
$x^{NORM} = 1/2$
$x^{STAND} = 1$

### 3. One-hot Encoding
$x_i^{ONEHOT} = \begin{cases} 1 & \text{if } x \in \text{Category } i \\ 0 & \text{if } x \notin \text{Category } i \end{cases}$

$x$ has length equal to number of categories.

### Example
Medical diagnosis task
Blood type: $(O, A, B, AB)$

$x = A, \quad x^{ONEHOT} = [0, 1, 0, 0]$
$x = AB, \quad x^{ONEHOT} = [0, 0, 0, 1]$

## Regularization
Choose parameters to minimize trade-off between $L$ and constraints (magnitude of parameters).

$\tilde{L} = L + \lambda \Omega(\vec{w})$

*   $L$: original loss function
*   $\lambda$: parameter controlling trade-off
*   $\vec{w}$: parameters

$\tilde{L} = L + \lambda \Omega(\vec{w})$

*   $L$: original loss function
*   $\Omega$: measure of magnitude of parameters

Typically, $\Omega$ is **L2 norm**
$\Omega(\vec{w}) = \frac{1}{2} \sum_j w_j^2$

$\tilde{L} = L + \frac{1}{2} \lambda \sum_j w_j^2$

We want to backprop to compute
$\frac{\partial \tilde{L}}{\partial w_i} = \frac{\partial L}{\partial w_i} + \lambda w_i$

In **L1 regularization**
$\Omega(\vec{w}) = \sum_j |w_j|$

$\tilde{L} = L + \lambda \sum_j |w_j|$

$\frac{\partial \tilde{L}}{\partial w_i} = \frac{\partial L}{\partial w_i} + \lambda \cdot \text{sign}(w_i)$

## Dropout
An ensemble of neural networks is less likely to overfit.

Train an ensemble of subnetworks of a neural network by randomly masking (multiply output by zero) neurons in network with probability $d$ (dropout rate).

1. All submodels share parameters.
2. Can use different dropout rates for different neurons.

At inference, use full model for prediction. Must multiply weights by $(1-d)$.
