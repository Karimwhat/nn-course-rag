## Learning on SOMs
Given a SOM with weights $w_{i,j}$  
$i$ - component  
$j$ - node  
and an input we learn in the following way.

0. Initialize nodes with random weights.
1. Given input $x$, find nearest node $w_k$.
   $$D(x, w_j) = \sum_i (x_i - w_{i,j})^2$$
   $$k = \text{argmin}_j (D(x, w_j))$$
2. Update weights.
   $$w_{i,j} \leftarrow w_{i,j} + \alpha \cdot h(j,k) (x_i - w_{i,j})$$
   $h(j,k)$ "neighbourhood function" - describes how near $w_j$ is to $w_k$  
   $\alpha$ - learning rate
3. Repeat over all inputs $x$. Until all inputs are mapped to the same node for several iterations.

### Adjacency Neighbourhood Function
$$h(j,k) = \begin{cases} 1 & \text{if } j=k \text{ or } j \text{ and } k \text{ adjacent} \\ 0 & \text{otherwise} \end{cases}$$

### Gaussian Neighbourhood Function
$$h(j,k) = e^{-\beta \|\vec{p}_j - \vec{p}_k\|^2}$$
$\vec{p}_i$ - position coordinates of node $i$ in graph  
$\beta$ - hyperparameter controlling width of Gaussian

### Quantization Error
$$QE = \sqrt{ \frac{1}{n} \sum_d \sum_i (x_i - w_{i,k})^2 }$$
$k$ - the closest node  
$d$ - sums over all inputs  
$n$ - number of inputs

### Topological Error
Given input $x$.  
$k$ - the nearest node  
$l$ - the second nearest node  
$$TE = \frac{1}{n} \sum_d (1 - h(k,l))$$

1. $w_{i,j} = w_{j,i}$

3. **Activation:**

Consider $x_i^B$ - output $i^{th}$ neuron before update  
$x_i^F$ - output $i^{th}$ neuron after update

$$x_i^F \sum_{j \neq i} w_{j,i} x_j - x_i^B \sum_{j \neq i} w_{j,i} x_j$$

**Case 1:** $x_i^F = x_i^B$  
Expression is zero

**Case 2:** $x_i^F = -x_i^B$  
Expression is positive

Any time a neuron's activation is updated $x_i \sum_{j \neq i} w_{j,i} x_j$ increases.  
This has an upper bound.  
The Hopfield network will converge to steady state.

**Stationary point:** A set of activations $x_i$ such that for all $i$:
$$x_i = a \left( \sum_{j \neq i} w_{j,i} x_j \right)$$

**Claim:** For input $\vec{x}$, $w_{j,i} = x_j x_i$ then $\vec{x}$ is a stationary point.

**Proof**  
$$a \left( \sum_{j \neq i} w_{j,i} x_j \right)$$
$$= a \left( \sum_{j \neq i} x_j x_i x_j \right)$$
$$= a \left( \sum_{j \neq i} x_j^2 x_i \right)$$
$$= a(x_i)$$
$$= x_i$$

Thus, the network converges to $\vec{x}$ if $w_{j,i} = x_j x_i$.

Analogously, if we want our network to converge to one of a set of patterns $\vec{x}^P$ then
$$W_{j,i} = \sum_p x_j^P x_i^P$$
