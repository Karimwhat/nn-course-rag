If input is of length $n$  
kernel is of length $k$  
then output is of length $n - k + 1$.

If we want output to be the same length as input then we can pad input with $\frac{k-1}{2}$ elements on each end.

### Example

**Valid padding** - only use valid elements from our input (i.e. no padding)

**Same padding** - pad input such that element [output] has same size as input.

### Stride
Only compute outputs $(x * w)(t)$ when
$$(t + \frac{k-1}{2}) \% s = 0$$

$s$ - stride

### Example
Kernel: $w(t) = \begin{cases} 1 & \text{if } -1 \le t \le 1 \\ 0 & \text{otherwise} \end{cases}$

| Index | 0 | 1 | 2 | 3 | 4 | 5 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **Input** | 0 | 2 | 7 | 9 | 8 | 4 |

[Applying stride $s = 3$:]

| Index | 1 | 4 |
| :--- | :---: | :---: |
| **Output** | 9 | 21 |

Stride $s = 3$

### Convolution in Neural Networks
For a given output $y_i$, the set of inputs that affect it are called the **receptive field**.

[Diagram: 6-node input grid mapping to a 5-node output grid using 3-node kernels.]

Like a fully connected layer with constraints:
1. All weights are zero outside receptive field.
2. Weights for all outputs are the same, but shifted in space.

COMP 4107 W2026 Page 4

---

What advantages do convolutional layers have?
1. More computationally efficient for modelling short-term dependencies.
   *   Fully connected layer: $(m+1) \times n$ parameters
   *   Convolutional layer: $k$ parameters
   *   $m$ - input length, $n$ - output length, $k$ - kernel width
2. Shared parameters across time/space. Features learned independent of location.

### Pooling
Computes a summary statistic of nearby inputs.
$$y_i = f(x_i, \dots, x_{i+c-1})$$

*   $c$ - constant (width of pooling operation).
*   Use with stride (often stride $c$).

Useful for downsampling.
1. Improves efficiency.
2. Makes network invariant to small translations.

---

Forms of pooling:
1. Max pooling: $f(x_i, \dots, x_{i+c-1}) = \max(x_i, \dots, x_{i+c-1})$
2. Avg pooling: $f(x_i, \dots, x_{i+c-1}) = \frac{1}{c}(x_i + \dots + x_{i+c-1})$

### Example
Pooling with width 2, stride 2.

| Index | 0 | 1 | 2 | 3 | 4 | 5 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **Input** | 2 | 9 | 18 | 24 | 21 | 12 |

**Max:**
| Index | 0 | 2 | 4 |
| :--- | :---: | :---: | :---: |
| **Value** | 9 | 24 | 21 |

**Avg:**
| Index | 0 | 2 | 4 |
| :--- | :---: | :---: | :---: |
| **Value** | 5.5 | 21 | 16.5 |

Often pooling is after convolution.

### Convolution in Higher Dimensions
Convolution in 2D:
$$(x * w)(s,t) = \sum_{a = -\infty}^{\infty} \sum_{b = -\infty}^{\infty} x(a, b) w(s-a, t-b)$$

COMP 4107 W2026 Page 6

---

Alternatively:
$$(x * w)(s,t) = \sum_{a = -\infty}^{\infty} \sum_{b = -\infty}^{\infty} x(s+a, t+b) w(a,b)$$

Typically define kernel
$$w(s,t) = \begin{cases} \text{non-zero} & \text{if } -c \le s, t \le c \\ 0 & \text{otherwise} \end{cases}$$

**Width** - number of non-zero elements in each dimension.

### Example
$$w(s,t) = \begin{cases} 1 & \text{if } -1 \le s, t \le 1 \\ 0 & \text{otherwise} \end{cases}$$

Kernel is $3 \times 3$ "width 3"

### Multi-Channel Convolution
$$(x * w)(s,t) = \sum_{a = -\infty}^{\infty} \sum_{b = -\infty}^{\infty} \sum_{c} x(s+a, t+b, c) w(a,b,c)$$
