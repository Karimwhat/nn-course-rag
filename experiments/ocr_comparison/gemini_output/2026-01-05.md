Artificial neural networks are machine learning models that are inspired by the biological brain.

**WHY NEURAL NETWORKS?**
* **Goal:** Use machines to automate tasks
* **Challenge:** Solving tasks for which the process of solving is difficult to describe (e.g. image or speech recognition)

**EXPERT SYSTEMS**
**Definition:**
A system which uses domain-specific knowledge to solve a task in a way similar to a human expert.

1. Devise a set of rules that describe a task environment
2. Use reasoning engine to answer questions

* Fred is a machine (while shaving).

**EXPERT SYSTEMS**
* Cannot handle noise
* It is difficult to devise accurate and complete rules
* Assigning things symbols add bias to our interpretation

---

**TRADITIONAL MACHINE LEARNING**
**Definition:**
Improving performance of a system on future tasks based on observations/data about the population

1. Extract a set of features from each population instance.
2. Learn relationships between features and labels.

---

**TRADITIONAL MACHINE LEARNING**
* Depends on the features we extract (how we represent inputs)

---

**REPRESENTATION LEARNING**
[Flowchart comparing four systems]
* **Rule-based systems:** Input $\rightarrow$ Hand-designed program $\rightarrow$ Output
* **Classic machine learning:** Input $\rightarrow$ Hand-designed features $\rightarrow$ Mapping from features $\rightarrow$ Output
* **Representation learning:** Input $\rightarrow$ Features $\rightarrow$ Mapping from features $\rightarrow$ Output
* **Deep learning:** Input $\rightarrow$ Simple features $\rightarrow$ Additional layers of more abstract features $\rightarrow$ Mapping from features $\rightarrow$ Output

*Goodfellow et al., Deep Learning Book, 2016.*

---

**POWER OF REPRESENTATION**
[Comparison of Cartesian vs. Polar Coordinates]
* **Cartesian coordinates:** A plot with $x$ and $y$ axes showing two classes (blue circles in center, green triangles in a ring).
* **Polar coordinates:** A plot with $r$ and $\theta$ axes showing the classes separated linearly (blue circles in a vertical band, green triangles in another).

*Goodfellow et al., Deep Learning Book, 2016.*

**DEEP LEARNING**
[Visual hierarchy of a neural network processing an image of a person]
* **Visible layer (input pixels)**
* **1st hidden layer (edges)**
* **2nd hidden layer (corners and contours)**
* **3rd hidden layer (object parts)**

**WHAT’S SO DEEP ABOUT DEEP LEARNING?**
* Repeated composition of functions
* Learn complex representations out of simple representations
